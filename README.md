getElementById : getElementById হল একটি মেথড যা একটি ইউনিক আইডি ব্যবহার করে নির্দিষ্ট এলিমেন্ট নির্বাচন করে। যেহেতু প্রতিটি আইডি প্রজেক্টে একবারই ব্যবহার করা হয়, তাই এটি দ্রুতগতিতে কাজ করে। এই মেথডটি সর্বদা একটি একক DOM এলিমেন্ট রিটার্ন করে।

getElementsByClassName হল এমন একটি মেথড যা একই ক্লাসযুক্ত সকল এলিমেন্টকে ধরতে পারে এবং তাদের HTMLCollection হিসেবে রিটার্ন করে। যেহেতু একাধিক  একই ক্লাস থাকতে পারে, তাই এটি একসাথে অনেক এলিমেন্ট ধরে।

querySelector হল এমন একটি মেথড যা একটি CSS সিলেক্টর ব্যবহার করে শুধুমাত্র একটি এলিমেন্টকে নির্বাচন করে। এটি সাধারণত একটি ক্লাস বা আইডি ধরে এবং দ্রুত কাজ করে।

querySelectorAll হল এমন একটি মেথড যা একটি CSS সিলেক্টর ব্যবহার করে সকল এলিমেন্টকে নির্বাচন করে। এটি সাধারণত সকল ক্লাস  দ্রুত কাজ করে। forEach লোপ ব্যবহার করা যায় ।
